🔁 AI Component Loop

Перенос паттерна AI-Scientist-v2 во фронтенд: draft → исполнение в песочнице → vision-ревью → improve. Лучший узел подсвечивается.

Без API-ключа: запросы идут через локальный мост, который использует уже авторизованный Claude CLI. Запустите node bridge.mjs и откройте страницу с него (порт 5173).
Ключ остаётся в браузере и шлётся только в API провайдера. Запускайте через локальный сервер (npx serve), не из file://, чтобы избежать CORS.
Аналогия с проектом: задача → _draft/_debug/_improve (parallel_agent.py), песочница = interpreter.py, vision-ревью = _analyze_plots_with_vlm, выбор лучшего = get_best_node.
